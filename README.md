# 小猪星球 🐷

一颗可以自由转动的 3D 小星球，上面住着 8 只做着自己喜欢的事的小猪：国王、飞行员、厨师、医生、甜品师、科学家、建筑工人、图书馆管理员。拜访完所有小猪后，可以点亮整颗星球，开启生日派对。

## 运行

单个 `index.html`，直接用浏览器打开即可（需要联网加载 three.js 和字体）。

- 链接末尾加 `#party` 可以直接解锁派对，方便测试
- 拜访进度存在浏览器 localStorage，测试后可以用无痕窗口重新体验

## 修改文字

- 小猪名字和台词：`index.html` 里的 `ROLES` 数组
- 飞机横幅：`BANNER_TEXT`
- 生日信：搜索 `class="body"`

## 技术

Three.js r160（CDN）· 程序化低多边形建模 · 卡通着色 · 无构建步骤
